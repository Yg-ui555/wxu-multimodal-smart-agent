## ❌ Bad Case #01: 政策类问题召回失败

**测试问题**：
1. "四六级考试报名通知"
2. "奖学金评定通知"

**期望行为**：召回"学校通知"目录下的四六级 / 奖学金相关文件

**实际行为**：召回完全不相关文档
- 马克思主义/马克思主义基本原理(2023年版).pdf
- 其他/第10章 电荷和静电场.pdf
- 实践/实习...金工实习报告...

**LLM 回答**："抱歉，资料库中没有找到相关信息。"

**🔍 根因分析（已确认）**：
- **A 类 - 知识库缺失**：grep 整个 `data/docs/` 验证，**奖学金、四六级相关文档 0 个**。
- B 类（次要）：chunk_size=800 + 同义词 gap。

**优化方向**：
- [ ] chunk_size 调到 500（更细粒度）
- [ ] 加 query rewriting（口语化 → 正式化）
- [ ] 加 metadata 过滤（按目录类别）
- [ ] 加 reranker（BGE-reranker / cohere-rerank）

## ❌ Bad Case #02: 培养方案类问题召回失败

**测试问题**：
- "大一上学期有啥课"

**期望行为**：召回培养方案 PDF，提取"大一第一学期课程表"

**实际行为**：召回上述不相关文档

**LLM 回答**："抱歉，资料库中没有找到相关信息。"

**根因分析**：
- 知识库内可能没有专门的"培养方案"PDF 文件
- 或有但被分类到"其他"，未被正确索引

**优化方向**：
- [ ] 确认培养方案文件是否在 knowledge base 中
- [ ] 如果不在，补充上传
- [ ] 如果在但检索不到：调 embedding 模型 / 优化分块

## ❌ Bad Case #03: 课程内容类问题召回失败

**测试问题**：
1. "信息论有啥题目"
2. "门电路相关知识"

**期望行为**：召回"信息论"或"数字电子技术"相关讲义 / 试卷

**实际行为**：召回完全不相关文档

**LLM 回答**："抱歉，资料库中没有找到相关信息。"

**根因分析**：
- 知识库中可能没有专门的"信息论"目录（部分内容可能在"其他"里）
- "门电路"在文档里可能叫"组合逻辑电路" / "数字电路"——同义词问题

**优化方向**：
- [ ] 同义词扩展（门电路 ↔ 组合逻辑电路）
- [ ] 关键词 + embedding 混合检索
