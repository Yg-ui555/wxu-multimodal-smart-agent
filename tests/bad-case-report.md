## 真失败（4 个）

### Case 1 - 校历：开学时间
- **题**：2024-2025 学年什么时候开学？
- **预期关键词**：`['2024', '9', '开学']`
- **状态**：`recall@4=True, precision=1.0, answer_hit=False`
- **检索源**：教学计划(2024-2025-2).pdf + 选课通知（很相关）
- **实际回答**："参考资料里没有直接写明2024-2025学年第二学期的开学日期...建议你查看无锡学院教务处官网"
- **根因**：**prompt 没强制"基于参考原文作答"**。检索命中了正确的 PDF（教学计划），LLM 看到参考里没写确切日期就绕开说"建议查官网"。
- **修法**：
  - 改 `src/rag/llm_chain.py` 的 prompt 模板
  - 加约束："若参考中无确切日期，**引用参考原文段落**而非建议查外部"
  - 加示例 few-shot："参考说'第 1 周开始上课'，应输出'根据 X 文档，2024-2025 第二学期课程从第 1 周开始'"

### Case 2 - 校历：寒假时间
- **题**：这学期什么时候放寒假？
- **预期关键词**：`['寒假', '1月']`
- **状态**：`recall@4=True, answer_hit=False`
- **根因**：与 Case 1 完全同源（LLM 看到参考里没写具体寒假时间就建议查官网）
- **修法**：与 Case 1 一次 prompt 修复覆盖两个

### Case 8 - 图书馆借几本书
- **题**：图书馆可以借几本书？
- **预期关键词**：`['借', '图书馆']`
- **状态**：`recall@4=False, precision=0.5`
- **检索源**：**"教材订购通知"**（完全不相关）
- **实际回答**："参考资料和对话历史里都没有图书馆借书数量的信息...一般高校本科生可借10到30册不等"
- **根因**：**KB 缺口**。查 `data/docs/图书馆/` 共 15 个文档，**全是图书馆通知（活动、评优、闭馆等），没有任何"借阅规则"或"图书借阅管理办法"**。
- **修法**：
  - 从图书馆官网 `https://lib.cwxu.edu.cn/` 找"图书借阅规则"或"读者入馆须知"
  - 抓 PDF → 清洗 → 保存为 `data/docs/图书馆/规则/本科生图书借阅管理办法.txt`
  - 重建向量库

### Case 10 - 你是谁
- **题**：你是谁？
- **预期关键词**：`['智能助手', '无锡学院']`
- **状态**：`recall@4=False, answer_hit=False`
- **检索源**：`[]`（空，KB 里没自我介绍）
- **实际回答**："我是无锡学院的智能校园助手，专门帮同学们解答校园生活、学习相关的问题..."
- **意外发现**：answer 里其实有"无锡学院"+"智能校园助手"，但 expected 要的是"智能助手"（不含"校园"），导致不匹配。这是 **双重问题**：
  1. **KB 缺口**：`data/docs/系统介绍/` 目录不存在，没有任何自我介绍文档
  2. **case 设计**：expected_keywords 与 LLM 实际措辞不匹配
- **修法**：
  - **修 KB**：创建 `data/docs/系统介绍/小U自我介绍.md`：
    ```markdown
    # 我是小U
    我是无锡学院智能助手，能帮同学查通知、课表、考试、奖学金等信息。
    ```
  - **改 case**：放宽 expected 为 `['智能', '助手']` 或 `['小U']`

## 假失败（2 个，纯 eval 设计问题）

### Case 14 - 组合逻辑电路（⚠️ 假失败）
- **题**：组合逻辑电路相关知识
- **预期关键词**：`['门电路', '组合', '逻辑']`
- **状态**：`recall@4=False, answer_hit=False`
- **检索源**：`[]`（空）
- **实际回答**："组合逻辑电路是数字电路中输出只取决于当前输入...常见类型有加法器、编码器、译码器、数据选择器和比较器..."
- **根因**：**eval 设计问题**。
  - sources 为空说明走了**常识路径**（没 KB）——这是预期的，数电常识题就该这么答
  - answer 含"组合"+"逻辑"+"数字电路"，但**没"门电路"**（答案从分类角度讲，没强调门电路）
  - expected_keywords 太严
- **修法**：**改 expected_keywords 为 `['组合逻辑', '数字电路']`**（更宽松，贴 LLM 实际答法）
- **修完后**：通过

### Case 15 - 选体育课规则（⚠️ 假失败）
- **题**：选体育课有什么规则？
- **预期关键词**：`['体育', '选修']`
- **状态**：`recall@4=False, precision=0.5, answer_hit=False`
- **检索源**：体育3选课通知 + 体育1选课通知（**很相关**）
- **实际回答**：列出了 4 条具体规则（自主选课、人数限定、康复保健班等）
- **根因**：**eval 设计问题**。
  - 检索是**成功**的（precision=0.5，召回到了相关文档）
  - answer 答得很好
  - expected 用了"选修"，answer 用的是"选课"——**同义词差异**
- **修法**：**改 expected_keywords 为 `['体育', '选课']`**（用更常见的"选课"替代"选修"）
- **修完后**：通过
